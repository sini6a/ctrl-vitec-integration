
# 📦 Vitec Integration Plugin v1.2.4

Stable release of the official WordPress plugin for displaying real estate listings via the Vitec API.

## ✅ What's New

- ✨ **New shortcodes** for filtered listings by status:
  - `[vitec-intaget]` – Status ID 2 (Intaget)
  - `[vitec-till-salu]` – Status ID 3 (Till salu)
  - `[vitec-sald]` – Status ID 4 (Såld)
  - `[vitec-referens]` – Status ID 10 (Referensobjekt)

- 🧹 Removed legacy shortcode `[vitec-integration-shortcode]`
- 🧭 Added button linking to Vitec API docs in admin panel
- 🔐 Tested up to WordPress 6.7.2
- 🧠 Improved PHPDoc, README and plugin metadata
